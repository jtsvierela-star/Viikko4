The Origin

At first I took a snapshot from the original server. Then i created a new server with similar specs using the snapshot.
After server was running started tweaking settings here and there. Both back up script and log file have their own folders at server 1.
Back up copies will be taken every hour and will be moved to server 2 via SSH connection.

For system poking and usage, the system has several users: ubuntu for administration and editing.
Ubuntu user get all necessary priviledges with sudo command. For server1, app user has right to increase
counter value. For server replication specific user has right to read binary logs and replicate database.

At server 2 application user can only use the SELECT command for reading database.
Back up files are only accessible for ubuntu user.
Lessons learned: do not copy database with CTRL C + CTRL V. Another lesson: follow instructions.

Database backups

In addition to continuous database replication, Server 1 creates a compressed MariaDB dump every night at 02:30.
The dump includes all databases, routines, events and triggers.
The backup is transferred to Server 2 using SSH.
Database backups are stored in:
/var/backups/db/
The retention policy removes database dump files older than 14 days.
